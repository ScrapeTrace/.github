# ScrapeTrace

**Tracing what happens when the web fights back.**

ScrapeTrace is an independent web scraping engineering lab created by [Logesh Krishna](https://github.com/Logesh08). We investigate the full path from requesting a page to extracting useful data.

## What we investigate

- **Research:** browser identity, TLS and HTTP behavior, automation signals, and anti-bot systems.
- **Extraction challenges:** scrambled fonts, honeypots, rendering, prompt injections, and data reliability.
- **Benchmarks:** controlled comparisons of scraping APIs, browser providers, proxies, latency, reliability, and cost.
- **Product analysis:** workload-specific evaluations with documented versions, test dates, and limitations.
- **Projects:** inspectable tools and reproducible experiments that make these systems easier to understand.

## How we work

Show the setup. Keep the evidence. Separate observations from explanations. Document limitations and provide enough detail for others to reproduce the work.

We evaluate technology within a specific test environment, disclose commercial relationships, and welcome corrections. Experiments use infrastructure we own or have permission to test.
